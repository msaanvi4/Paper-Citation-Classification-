Paper Citation Classification - expected starter files

IMPORTANT:
- dataset/dataset.csv is a HEADER-ONLY TEMPLATE. Replace it with your actual dataset.
- models/trained_model.pkl is intentionally NOT included. It must be generated by training on the real dataset.
- The class thresholds in src/preprocessing.py are Low <= 918, Medium 919-1384, High >= 1385. Verify these against the team's agreed methodology before using results.
- The evaluation script generates results/metrics.json, results/classification_report.txt, and results/confusion_matrix.png.
- This starter uses a single Logistic Regression pipeline. If your teammate has already implemented different models, integrate the code rather than overwriting their work.

From the project root in PowerShell:
  python -m pip install -r requirements.txt
  python -m src.train
  python -m src.evaluate
  python -m src.predict --title "Example paper title" --abstract "Example abstract" --year 2024 --authors 4 --field "Computer Science"

The dataset must include:
paper_id (optional), title, abstract, publication_year, author_count, primary_field, citation_count

Do not use citation_count as a model input; it defines the target category and would leak the answer.
